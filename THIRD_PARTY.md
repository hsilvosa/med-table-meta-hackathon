# THIRD_PARTY

Hackathon rule: judges must be able to tell what was built during the event. This file separates what is new work in this repository from what is reused.

## Built in this repository (new work)
Everything tracked in git except `demo_cache/` and the box and pill pictures in `web/world_demo/assets/` (from AEMPS CIMA, listed below): `src/medtable/`, `scripts/`, `experiments/`, `web/`, `tests/`, `PLAN.md` and the READMEs. See `git log`.
